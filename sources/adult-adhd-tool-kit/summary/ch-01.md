# Ch 1 — Introduction

**Source:** Ramsay & Rostain, *The Adult ADHD Tool Kit*. **Citation convention:** the EPUB has no page numbers, so every cite is "Ch 1, §<section heading>"; page = n/a (unverified against the print edition).

## 1. Main idea
ADHD is framed as a developmental disorder of executive function and motivation: people know what to do but cannot reliably follow through when payoff is delayed (Ch 1, §Adult ADHD Background). The book is a patient companion to the authors' CBT treatment manual; its focus is *implementing* familiar coping skills, using externalized written reminders ("Take Away" boxes) (Ch 1, §Development of the Adult ADHD Tool Kit).

## 2. Named methods / routines
- **"Start small" goal-setting** (Ch 1, §Development…): (1) pick a specific behavior in a specific setting; (2) name one positive behavior to increase; (3) name one interfering behavior to decrease. Example: organize mail daily; put action items (bills) in a shoe box on the desk; no TV until mail is checked. Duration: not stated.
- **Procrastination profile** (Ch 1, opening): a framework for seeing how ADHD affects thoughts, feelings, and task management; detail is deferred to later chapters (the section's start is cut off in the EPUB — see gaps.md).
- **Chapter sequence:** planning/prioritizing first, then other skills, then application to school, work, relationships and special topics (Ch 1, §Development…).

## 3. Tools / containers (one job each)
- Written take-away reminders ("hard copy of instructions akin to a recipe"): keep handy so skills are portable (Ch 1, opening).
- Shoe box on desk: holds bills/items needing action (example only) (Ch 1, §Development…).
- The tool kit itself: "read, used, marked up, dog-eared" (Ch 1, end).

## 4. Notes, thoughts, reference material
Not addressed as a system. Only principle: "externalization of information" — write plans/skills out rather than hold them in mind (Ch 1, §Development…).

## 7. Key terms
- **Executive functions** — Barkley's definition: "the use of self-directed actions so as to choose goals and to select, enact, and sustain actions across time toward those goals…" (Ch 1, §Adult ADHD Background). Also described via "conductor"/"manager" metaphors.
- **Kessler et al. (2010) factors** — time management; organization/problem solving; self-motivation; impulse control (inhibition); emotional management (Ch 1).
- **Externalization of information** — seeing plans/skills written out instead of held in mind raises odds of executing them (Ch 1, §Development…).
- **Braided cord** — the interlocking of ADHD, coping frustration, negative thoughts, distress and avoidance (Ch 1, §Development…).
- **"Remember to remember"** — goal that the reader recalls the skills when they count (Ch 1).
- **Start small** — see §2.
